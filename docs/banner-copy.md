# 박사장 클라쓰 · 랜딩 배너 문구 (손해 방지형)

> 랜딩페이지 배너와 광고에 쓸 문구. 고객이 "박사장이 내 손해를 막아주겠구나"라고 느끼도록,
> 손해를 먼저 보여주고 박사장이 막아준다는 약속을 붙인 구조.
> 숫자는 한 줄에 하나, 근거로만 사용한다.

## 배너 문구 3종

| # | 배너 메인 문구 | 작은 서브 문구 | 쓰임새 | 들어간 숫자 |
|---|---|---|---|---|
| ① | 창업 실수, 비싼 수업료 내지 마세요 | 혼자 부딪히기 전에, 박사장이 놓치기 쉬운 것부터 짚어드려요 | 메인 배너 (랜딩 상단 · 인스타 프로필) | 없음 |
| ② | 오픈 날 실수는 그대로 손해가 됩니다 | 두 번 열어본 박사장이 D-7부터 함께 점검해드려요 | 박람회 전단 · D-7 체크리스트 광고 (오픈 단계 사장님) | 두 번, D-7 |
| ③ | 버리는 재고, 나가는 알바, 새는 매출 | 혼자 시작해 월 매출 4천만 원을 만든 박사장이 먼저 잡아드려요 | 셀프 진단 · 프리미엄 현장 컨설팅 배너 (운영 단계 사장님) | 4천만 원 |

## 각 문구가 주는 느낌

- ① "내 돈으로 실수하면서 배울 필요 없다"는 자극. 브랜드 전체를 대표하기 좋아 메인 배너로 사용.
  서브 문구는 히어로 헤드라인 B안과 앞부분·끝부분 모두 겹치지 않게 따로 씀. 배너는 A안·B안에 똑같이 보이므로 H3 테스트의 차이는 헤드라인 하나로 유지됨.
- ② 오픈을 앞둔 사장님의 불안을 바로 건드림. 무료 D-7 체크리스트 CTA와 바로 이어짐.
- ③ 이미 장사 중인 사장님이 매일 겪는 손해 세 가지를 나열. 셀프 진단 링크와 함께 사용.

## 쓸 때 지킬 것

- "매출 보장", "실패 없음", "무조건 대박" 같은 약속은 쓰지 않는다 (가이드북 1-4 '쓰지 않을 말').
- "막아드려요"가 너무 단정적으로 느껴지면 "줄여드려요"로 바꿀 수 있다.
- 매출 숫자는 실제 매출일지 기준만 쓴다. '4배'는 쓰지 않는다 (실제는 약 2.7배).

## 확정 슬로건 (가이드북 1-4)

1. 알바에서 사장까지 8년, 먼저 겪은 박사장이 미리 막아드려요 (메인, 3-3 헤드라인 B안과 동일)
2. 오픈 날 당황하지 않게, 두 번 열어본 사장이 함께합니다
3. 혼자 시작해 월 매출 4천만 원, 그 방법 그대로 드려요

## 근거 숫자 (매출일지, 2023.02 오픈 ~ 2026.05)

- 첫 정식 영업 달 2023.03: 월 1,567만 원 · 주문 697건
- 최고 달 2025.07: 월 4,246만 원 · 주문 1,579건 (약 2.7배)
- 최고 월 주문: 2025.11 · 1,729건
- 하루 최고 매출: 2025.10.06 · 222.9만 원 · 80건
- 월 매출 2천만 원 돌파 2024.04 → 3천만 원 2024.07 → 4천만 원 2025.06
- 객단가 2만 2천~2만 8천 원대
- 배달 비중: 배민 약 80% → 쿠팡이츠 최대 45% (2025.11)

## 랜딩에 넣을 때 (Claude Code 프롬프트 예시)

```
docs/banner-copy.md 의 배너 문구 3종을 랜딩에 넣어줘.
- ① 메인 배너는 히어로 바로 위 또는 아래에 띠 배너로
- ② 는 경로 A 체크리스트 신청 페이지 상단에
- ③ 은 경로 B 셀프 진단 시작 화면 상단에
- 메인 문구는 크게, 서브 문구는 작게. 브랜드 컬러(남색 #1F3A5A, 주황 #D9622B) 사용
- 문구는 파일 그대로 쓰고 바꾸지 마
```
