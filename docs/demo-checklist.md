# 발표 시연 전 체크리스트

A/B 테스트가 켜져 있어 방문자마다 헤드라인(H3)과 완료 화면 배너(H1)가 무작위로 정해집니다. 완료 화면 배너가 `off` 로 배정되면 "템플릿 보러 가기" 버튼이 보이지 않아 경로 A 시연이 끊깁니다. 시연할 브라우저에서 그룹을 미리 고정합니다.

시연 주소: https://parksajang-class.vercel.app

## 그룹 고정 (PC 브라우저)

- [ ] 시연에 쓸 브라우저를 엽니다. 시크릿 창은 닫으면 설정이 사라지므로 시연 때 쓸 창에서 그대로 진행합니다.
- [ ] 위 시연 주소를 엽니다.
- [ ] `F12` 를 눌러 개발자 도구를 열고 **Console** 탭으로 갑니다.
- [ ] 아래 두 줄을 붙여 넣고 `Enter` 를 누릅니다. 붙여넣기가 막히면 안내대로 `allow pasting` 을 입력한 뒤 다시 붙여 넣습니다.

```js
localStorage.setItem('psc_exp_headline', 'a');
localStorage.setItem('psc_exp_done_offer', 'on');
```

- [ ] 개발자 도구를 닫고 페이지를 새로고침합니다.

| 값 | 의미 |
|---|---|
| `psc_exp_headline` = `a` | 헤드라인 A안 "AI가 모르는 오픈 현장, 두 번 열어본 박사장이 알려드려요" |
| `psc_exp_done_offer` = `on` | 신청 완료 화면에 템플릿 샘플 · 할인 배너 · "템플릿 보러 가기" 표시 |

## 경로 A 리허설

- [ ] 랜딩에 A안 헤드라인이 보입니다.
- [ ] "무료 D-7 체크리스트 받기"를 누르면 신청 폼으로 넘어갑니다.
- [ ] 신청 완료 화면에 "템플릿 보러 가기" 버튼이 보입니다.
- [ ] 템플릿 상세 → 주문서 → "결제하기 (데모)" → 구매 완료까지 이어집니다.

## 상황별 대처

| 상황 | 방법 |
|---|---|
| 콘솔을 쓸 수 없는 기기 (휴대폰 등) | PC로 시연하거나, 신청 뒤 주소를 `checklist-done.html?offer=on` 으로 바꿔 엽니다 |
| B안 헤드라인을 보여주고 싶을 때 | 주소에 `?v=b` 를 붙입니다. 저장된 그룹은 바뀌지 않습니다 |
| 이벤트 로그를 보여주고 싶을 때 | 주소에 `?debug=1` 을 붙입니다. `?debug=0` 으로 끕니다 |

## 참고

- 시연 방문도 GA4에 기록되어 H1·H3 실험 데이터에 섞일 수 있습니다. 분석할 때 시연 시간대를 감안합니다.
- 시연이 끝난 뒤 같은 브라우저를 다시 무작위 배정 상태로 되돌리려면 콘솔에서 아래를 실행합니다.

```js
localStorage.removeItem('psc_exp_headline');
localStorage.removeItem('psc_exp_done_offer');
```
